## About the Project
Sprout [change] takes long-term or overwhelmed goals and breaks them down into actionable steps using AI. As you complete tasks on your interactive canvas or sidebar checklist, your personal grove sapling grows into a flourishing tree.

## Features
* **AI Search Engine Interface:** Enter raw goals or pick from prompt suggestions.
* **Prezi-style Zoomable Canvas:** Visual node map to expand and collapse goal structures.
* **Dynamic Tree Growth:** Visual progress tracker that evolves as tasks are checked off.
* **Calendar Reminders:** Quick dynamic links to schedule sub-tasks into your calendar.
* **Cozy Enchanted Grove Aesthetics:** Warm visuals, earthy tones, and soothing ambient design.
